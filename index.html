先連結共用資料

每次開啟網頁都必須重新讀取最新的共用 JSON。

HTML 必須先複製到這台電腦的本機磁碟再開啟；FTP 只保留下列固定資料檔：

DocCCC-data.json
  1. FTP 顯示在 Windows「網路位置」時，按橘色按鈕安全開啟既有 JSON。
  2. 確認資料後，再按藍色按鈕允許寫入；選取檔案本身不會進入另存或清空流程。
  3. 載入完成後，暫存、提交與其他正式資料變更都會寫回同一檔案。
  4. 一般本機或可選取的共享資料夾，仍可使用綠色按鈕自動同步。
  5. 多人修改不同表單或欄位時會自動取聯集；同一欄位在五分鐘內同時修改才會要求選擇。

尚未連結共用資料。

此瀏覽器不支援直接覆寫檔案。仍可匯入資料，但修改後必須使用「匯出資料」下載並手動覆蓋共用 JSON；建議改用最新版 Edge 或 Chrome。
